Do's & Don'ts

✓ Do

  • Use #f6f8fb canvas with pure #ffffff cards so panels read as floating.
  • Reserve #1473ff for primary action, links, and focus rings only.
  • Separate surfaces with the #dde1e7 hairline border, not shadows.
  • Set headings in Lexend with -0.025em tracking at weight 600–700.
  • Render code and API keys on the #0d1117 surface with monospace.
  • Use pill badges (#e8f1ff / #0d55c4) for eyebrows and pricing tags.

✕ Don't

  • Don't add gradients or glows — the source has none.
  • Don't use #1473ff for large fills or body text.
  • Don't drop heavy shadows; a 1px border is the elevation cue.
  • Don't mix the dark .dark palette into the light theme.
  • Don't set headings without tight tracking — it breaks Lexend's voice.
  • Don't enlarge button radius into pills; pills are for badges only.
