Nhà cung cấp đã được xác minh

Mọi nhà cung cấp đều được xem xét trước khi hoạt động. Các số liệu về thời gian hoạt động, độ trễ và tỷ lệ thành công theo thời gian thực đều được công khai.

Trả tiền theo Token

Không có gói đăng ký, không có chỗ ngồi. Nạp tiền vào ví của bạn và chỉ trả tiền cho các token bạn thực sự tiêu thụ.

Phân tích sử dụng

Số lượng token, phân tích chi phí, biểu đồ độ trễ và toàn bộ nhật ký yêu cầu có thể nhìn thấy trên bảng điều khiển theo thời gian thực.

Bảo mật theo thiết kế

Khóa API được băm SHA-256. Các khóa API của nhà cung cấp được mã hóa AES-256-GCM. Xác thực JWT với token thời gian ngắn.

OpenAI/Anthropic compatible

Tương thích với công cụ AI bạn đang dùng

Dùng model từ Foza trong các editor, CLI và agent framework phổ biến chỉ bằng base URL và API key.

OpenCode

CLI

Cấu hình Foza như provider OpenAI-compatible cho các workflow local.

config
# ~/.config/opencode/config.json
"providers": {
  "foza": {
    "base_url": "https://api.foza.ai/v1",
    "api_key": "sk-foza-xxxx"
  }
}

Cursor

AI Editor

Dùng trong editor AI với base URL tùy chỉnh và model alias của Foza.

config
# Cursor Settings → Models
Override AI Base URL:
  https://api.foza.ai/v1
 
API Key: sk-foza-xxxx
Model:   provider/gpt-4o

Claude Code

CLI Agent

Kết nối các model Claude-compatible hoặc route qua gateway cho tác vụ coding.

config
$ ANTHROPIC_BASE_URL=\
    https://api.foza.ai/v1 \
  ANTHROPIC_API_KEY=sk-foza-xxxx \
  claude

Codex CLI

Terminal

Chạy tác vụ terminal với một khóa API và danh sách model thống nhất.

config
$ OPENAI_API_KEY=sk-foza-xxxx \
  OPENAI_BASE_URL=\
    https://api.foza.ai/v1 \
  codex "Fix the bug in main.ts"
OC

OpenClaw

Agent

Gắn gateway vào agent runtime để chuyển model mà không đổi logic.

config
# openclaw.config.ts
llm: {
  provider: "openai",
  base_url: "https://api.foza.ai/v1",
  api_key: "sk-foza-xxxx",
  model: "provider/claude-sonnet-4.6"
}
HA

Harness Agent

Workflow

Dùng trong workflow agent có kiểm soát chi phí, token và log.

config
# harness-agent.yaml
ai_provider:
  type: openai_compatible
  base_url: https://api.foza.ai/v1
  api_key: ${{ secrets.FOZA_KEY }}
  model: provider/gpt-5.4

Base URL dùng chung

https://api.foza.ai/v1 — drop-in replacement for any OpenAI base URL

Cách thức hoạt động

Từ lúc bắt đầu đến khi nhận được phản hồi AI đầu tiên trong vòng chưa đầy 5 phút.

01

Tạo tài khoản

Đăng ký bằng email hoặc Google trong vòng chưa đầy 30 giây.

02

Tạo khóa API

Tạo một khóa trong bảng điều khiển và đăng ký nó với bất kỳ mô hình nào.

03

Gọi API

Sử dụng bất kỳ SDK tương thích OpenAI nào, chỉ cần thay đổi URL cơ sở và khóa.

04

Theo dõi và mở rộng quy mô

Theo dõi chi tiêu, token và độ trễ. Nạp tiền và tiếp tục sử dụng.

Kiếm tiền từ
quyền truy cập API của bạn

Đang trả tiền cho GPT, Claude hoặc chạy các mô hình của riêng bạn? Biến điều đó thành thu nhập. Đăng ký, liệt kê các mô hình của bạn với giá tùy chỉnh và kiếm tiền trên mỗi token người mua gửi.

  • Tự thiết lập giá trên mỗi token
  • Tận dụng quyền truy cập API hiện có của bạn
  • Thu nhập được cộng vào ví cho mỗi yêu cầu
  • Phân tích sử dụng cho từng mô hình
  • Không cần thay đổi cơ sở hạ tầng
  • Sự phê duyệt của quản trị viên đảm bảo chất lượng nền tảng
